# Business Flights Travel — Design System

Documents the design language actually established in this codebase, for
Claude/Impeccable/any future design pass to work *with* rather than
reinvent. Written from a direct audit of the source (globals.css,
component classNames, the Hero/Header/Footer/forms), not generated by a
browser extension — this environment has no path to load a Chrome
extension, so `design-md-chrome`'s output format is reproduced by hand
here instead.

## Brand character

Premium, editorial, understated-luxury business travel agency. Not a SaaS
product, not a generic travel blog. Reference points: business-class
airline brand pages, editorial travel journalism — not Stripe/Linear/
Vercel-style tech-SaaS design (no glassmorphism, no purple-blue AI
gradients, no floating orbs).

## Color

Three-family palette, one accent — deliberately not more:

| Token | Hex | Use |
|---|---|---|
| `--color-navy-950` | `#0a1a30` | Primary text, dark section backgrounds |
| `--color-navy-900`–`700` | `#0d2340`–`#1b4269` | Headings on light, secondary dark surfaces |
| `--color-navy-600`/`500` | `#2a5686`/`#3d6da3` | Rarely used — lighter navy accents |
| `--color-gold-400`/`500` | `#e3b876`/`#d29c4a` | The one accent — CTAs, kickers, highlights |
| `--color-gold-600`/`700` | `#946824`/`#76531d` | Gold used as *text* (WCAG AA-adjusted — see the comment in globals.css) |
| `--color-cream-50`/`100` | `#fbf9f5`/`#f5f1e8` | Page background, light section fills |

No pure black, no pure white background. No second accent color. Every
dark section uses the same navy-950, never a different "brand dark."

## Typography

- Display/headings: **Playfair Display** (`--font-display`) — editorial
  serif, used for every `h1`–`h4`.
- Body: **Instrument Sans** (`--font-sans`) — deliberately not Inter,
  which reads as the default of template/AI-generated sites.
- Kickers/eyebrows: `text-xs font-semibold tracking-[0.2em]` to
  `tracking-[0.3em]` uppercase, in gold-600.
- Headline sizing uses `clamp()` for fluid scaling (e.g.
  `text-[clamp(2rem,6vw,3.75rem)]`) rather than fixed breakpoint jumps.

## Spacing & layout

- Section vertical rhythm: `py-14 sm:py-20` (small sections) up to
  `py-16 lg:py-24` (page heroes) — not `py-24`+ everywhere; this site
  doesn't chase maximal whitespace, it uses *consistent* whitespace.
- Content containers: `max-w-7xl` for full-width sections, `max-w-5xl`/
  `max-w-3xl`/`max-w-4xl` for reading-width content (articles, FAQ, forms).
- No CSS Grid "bento" asymmetry, no negative-margin overlapping cards —
  layouts are honest grids and image/text splits (see
  `BusinessClassHighlights.tsx` for the standard 50/50 image+content
  pattern).

## Motion

- `Reveal.tsx`: the one entrance-animation primitive, used everywhere.
  `whileInView`, `once: true`, custom cubic-bezier `[0.16, 1, 0.3, 1]`,
  `y: 20` translate + opacity, 0.55s. Transform/opacity only — no
  layout-triggering properties animated.
- `MotionConfig reducedMotion="user"` wraps the whole app
  (`MotionProvider.tsx`) so every Framer Motion animation respects
  `prefers-reduced-motion` automatically; `globals.css` has the matching
  CSS-level override for non-Motion transitions.
- No parallax, no scroll-jacking, no 3D. Hover states are simple
  color/scale transitions (`hover:scale-[1.03]` on the odd primary CTA),
  not physics-simulated "magnetic" effects.

## Components

- Cards: no default `border + shadow + white background` treatment stacked
  on every element — `TrustSection.tsx`'s feature grid uses a top border
  rule instead of a boxed card, for instance. Where an actual card exists
  (destination cards, blog post cards, FAQ items), it's deliberately
  restrained: `rounded-xl`/`rounded-2xl`, a hairline border or none, no
  heavy shadow except on the flight-request form itself (which earns its
  elevation as the page's primary action).
- Buttons: filled pill (`rounded-full`) in navy-950 or gold-500,
  `hover:bg-[gold-600 or gold-400]`. No secondary "ghost" button pattern
  repeated everywhere — CTAs vary between filled pill and plain text link
  with an arrow, by context.
- Icons: `lucide-react`, `strokeWidth={1.75}` where set explicitly —
  restrained use (trust-section feature icons, form field icons), never
  decorative icon soup.

## What NOT to do here

- Don't introduce a second accent color.
- Don't add glassmorphism/backdrop-blur to content sections (the sticky
  header's blur-on-scroll is the one legitimate use — a fixed element).
- Don't add gradient hero backgrounds beyond the existing photo-darkening
  overlay pattern (`bg-gradient-to-b from-navy-950/35 via-navy-950/55 to-navy-950`).
- Don't reach for 3D/WebGL — evaluated for this project and declined (see
  the audit report); it doesn't fit the editorial-print-adjacent feel this
  site is going for, and the performance/accessibility tradeoff isn't
  worth it for a travel agency's conversion-focused pages.
